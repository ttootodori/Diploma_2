# API автотестирование (Rest Assured + Allure)

## Описание
Проект с автоматизированными тестами для REST API.  
Демонстрирует навыки тестирования API, параметризации тестов и формирования детальных отчётов.

---

## Стек технологий
- **Java**
- **JUnit 4**
- **Rest Assured** (API-запросы и валидация)
- **Allure** (отчёты о тестировании)
- **Maven** (сборка проекта)

---

## Что протестировано
- **3 API endpoints**
- **15 автотестов**, в том числе:
  - 2 параметризованных теста
- Валидация:
  - статус-кодов
  - структуры JSON-ответов
  - корректности данных

---

## Как запустить тесты
```bash
mvn clean test
```
# API Testing (Rest Assured + Allure)

## Description
Automated tests for REST API.  
Demonstrates API testing skills, test parameterization, and detailed reporting.

---

## Tech Stack
- **Java**
- **JUnit 4**
- **Rest Assured** (API requests and validation)
- **Allure** (test reporting)
- **Maven** (build tool)

---

## What was tested
- **3 API endpoints**
- **15 automated tests**, including:
  - 2 parameterized tests
- Validation of:
  - status codes
  - JSON response structure
  - data correctness

---

## How to run tests
```bash
mvn clean test
```
